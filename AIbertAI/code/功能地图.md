# MonkeyAI 桌面客户端 功能地图

依据:`rea-out/code/`(主进程未混淆源码 + 渲染端格式化 bundle),静态提取。
标注:✅=直接观察到的代码事实;推测=合理推断未逐行验证;未知=未验证。

## 1. 总体架构

```
MonkeyAI-latest-win-x64.exe (NSIS-3, EV签名: 北京长亭未来科技有限公司)
 └─ app-64.7z → Electron 44.1.1 运行时 (MonkeyAI.exe)
     ├─ app.asar
     │   ├─ out/main/index.js        ← 主进程:窗口/托盘/通知/视图 (1.2MB, 可读)
     │   ├─ out/main/index-CJpHFiCP.js ← 主进程:内嵌 Hono 本地服务 + MCP + 代理清理 (7.5MB, 可读)
     │   ├─ out/preload/index.js     ← 预加载:monkeyai 桥 (117 IPC 通道 + capability 权限模型)
     │   └─ node_modules/ (112 包)
     ├─ resources/web/               ← 渲染端 React UI (393 JS, React+zh-CN)
     ├─ app.asar.unpacked/           ← 原生二进制:sharp(图像) + vectorizer(位图转矢量)
     └─ app-update.yml               ← 更新: 部署方的发布服务器
```

数据流:渲染端 `window.monkeyai.*` → preload 校验 capability → `ipcRenderer.invoke("域:动作")` → 主进程 handler;
主进程内嵌本地服务 ←→ 渲染端浏览器上下文(ws://127.0.0.1:* 放行)。

## 3. preload 桥(monkeyai / ohosTitlebar)

- `exposeInMainWorld("monkeyai")` — 主桥 ✅
- `exposeInMainWorld("ohosTitlebar")` — 自定义标题栏(拖拽/关闭/最小化/最大化)✅
- **capability 权限模型** ✅:工具级声明 scope(device/session)× mode(read/ephemeral/operation)× 权限(session:read/session:control/files:read/files:write),含远端策略解析(≤512 工具)
- **DESIGN_UI_TOOLS**(设计工具白名单,30+):canvas_get/apply/duplicate/select/import_image/import_video/import_audio/export_pptx/render_slide/create_image/video/text/html、design_fonts/features/catalog/style_decision/system_set、media_project 系列、gif 时间线展开等 ✅

## 4. 渲染端(resources/web/,React)

- 技术栈:React(zh-CN)+ vite 产物 + Shiki 语法高亮(377 个语言包 chunk)+ Marp(PPT 预览)+ mermaid(图示)+ cynefin ✅
- 路由表(react-router,观察到的字面量)✅:

| 路由 | 功能 |
|---|---|
| `/` | 首页/工作台 |
| `/login` | 登录 |

| `/knowledge-bases/:id` | 知识库详情 |
| `/settings/:section?` | 设置(分节) |

- UI 语义对照(推测):AI 会话工作台 + 项目 + 知识库 + 媒体创作(PPT/视频/GIF)+ 设计专家 + 内置浏览器
